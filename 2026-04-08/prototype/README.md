# InvoicePilot プロトタイプ

請求書受領から仕訳・承認までを自動化する AI マネージドサービスのプロトタイプ。

## コンセプト

AI エージェント + ハーネス + 決定論的コードの三位一体アーキテクチャで、
「請求書処理の完成品」を提供します。

## セットアップ

```bash
cd 2026-04-08/prototype
npm install
```

## デモ実行

### モックモード（APIキー不要）

```bash
npm run demo:mock
```

### 実APIモード（Anthropic APIキー必要）

```bash
export ANTHROPIC_API_KEY=your-key-here
npm run demo
```

## ディレクトリ構成

```
prototype/
  harness/          # ハーネス層（ライフサイクル管理）
    lifecycle.ts    # before/after フック定義
    checker.ts      # 品質チェック総合判定
    planner.ts      # 終了条件の外部管理
  agent/            # AIエージェント層
    index.ts        # Claude API による請求書データ抽出
  deterministic/    # 決定論的コード層
    rules.ts        # 税計算・仕訳生成・承認ルーティング
  knowledge/        # ナレッジ管理
    store.ts        # 取引先-勘定科目マッピングの永続化
    improver.ts     # 自動改善ループ（修正蓄積と提案生成）
  demo/             # デモ用エントリポイント
    run.ts          # パイプライン全体の実行デモ
  data/             # ランタイムデータ
    knowledge-base.json      # 蓄積されたナレッジ
    improvement-queue.json   # 改善提案キュー
```

## パイプラインの流れ

デモでは以下のステップを順に実行します。

1. **パイプライン状態の生成** — 終了条件チェックリストを初期化
2. **前処理チェック** (`beforeExtraction`) — 請求書テキストの妥当性を確認
3. **AI抽出** — Claude API で請求書テキストから構造化データに変換
4. **抽出バリデーション** (`afterExtraction`) — 必須フィールド・金額整合性を検証
5. **仕訳生成** — 決定論的ルールで勘定科目を決定し仕訳を起票
6. **仕訳バリデーション** (`beforeJournalEntry`) — 借方貸方一致・勘定科目の有効性を確認
7. **品質チェック** — パイプライン全体の信頼度スコアを算出
8. **承認フロー** — 金額閾値に応じた承認レベルを決定（デモでは自動承認）
9. **ナレッジ記録** — 知識ベースに取引パターンを保存
10. **改善提案表示** — 修正蓄積に基づく改善提案を確認

## アーキテクチャの特徴

### ハーネスによるドリフト対策
- AI エージェントは自分で「完了」を宣言できない
- 終了条件はプランナーがチェックリストとして外部管理
- 各ステップの出力は決定論的バリデーションを通過しなければ次に進めない

### 自己改善ループ
- ユーザーの仕訳修正を自動的にナレッジとして蓄積
- 修正頻度が閾値（3 回）を超えたら改善提案を自動生成
- 提案の反映は必ず人間が承認（ヒューマン・イン・ザ・ループ）

### 決定論的ルール
- 税計算（標準税率 10%・軽減税率 8%）
- 承認ルーティング（10 万円未満: 担当者、10 万円以上: 課長、50 万円以上: 部長、100 万円以上: 役員）
- 重複の請求書検出（同一取引先・日付・金額）
