# ターゲットドメイン選定

日時: 2026-04-01
選定ドメイン: **経理・請求書処理**

## 選定理由

1. **コモディティ性が極めて高い**: 請求書処理はほぼ全企業に共通する業務であり、競争優位に直結しない。内製するインセンティブが低く、マネージドサービスの経済合理性が最も高いドメインの一つ。

2. **AI/決定論的コードの分離が明確**: 請求書のフォーマット解析・項目抽出はAIの推論アップサイドが大きく（多様なフォーマット対応）、一方で仕訳ルール適用・税計算・承認ワークフローは決定論的コードで確実に処理すべき領域。三位一体アーキテクチャの実証に最適。

3. **ハーネスの価値が明確**: 請求書処理は「抽出→照合→仕訳→承認→記帳」という明確なライフサイクルを持ち、各ステップでの品質チェック（金額整合性、仕訳科目の妥当性）をハーネスが管理する構造が自然に成立する。

4. **ドリフト問題が具体的に発生しうる**: AIが「この請求書は処理完了」と自己申告しても、実際には照合ミスや仕訳誤りがある可能性がある。ハーネスによる外部バリデーションの必要性を強く示せる。

5. **自己改善ループが設計しやすい**: ユーザーの修正履歴（仕訳科目の訂正等）がそのまま学習データとなり、時間とともに精度が向上するループを自然に組める。
