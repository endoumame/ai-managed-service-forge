# ターゲットドメイン選定

## 選定日: 2026-04-15

## 選定ドメイン: 経理・請求書処理

## 選定理由

1. **コモディティ性が極めて高い**: 請求書処理は全企業に共通する業務であり、競争優位に直結しない典型的なバックオフィス業務である。内製する動機が薄く、マネージドサービスの対象として最適。

2. **ハーネスの価値が明確**: 請求書処理は「OCR/AI 読取 → 仕訳分類 → 承認 → 会計ソフト連携」という明確なライフサイクルを持ち、各ステップに品質チェック（金額の整合性、勘定科目の妥当性）を挟む必要がある。AI に自己完結させると金額誤認や誤仕訳のリスクが高いため、ハーネスによる外部バリデーションが不可欠。

3. **ドリフト問題が顕在化しやすい**: 大量の請求書をバッチ処理する際、AI が途中で「もう十分」と判断したり、フォーマットの微妙な違いに対して累積的にズレたりする典型的なケース。ハーネスによるドリフト対策の価値を実証しやすい。

4. **自己改善ループが自然に成立する**: ユーザーが仕訳を修正するたびに、その修正データが蓄積され、次回以降の仕訳精度が向上する。フィードバックループの設計がシンプルかつ効果的。

5. **初回実行として最適**: プロトタイプの実現可能性が高く、JSON 請求書データ → AI 仕訳分類 → 人間承認 → ナレッジ更新というフローを CLI デモで十分に表現できる。
