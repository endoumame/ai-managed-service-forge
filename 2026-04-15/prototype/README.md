# InvoiceForge — AI請求書仕訳オートパイロット プロトタイプ

請求書データを投入するだけで、AI が勘定科目を推論し、ハーネスが金額整合性と仕訳妥当性を検証し、人間の承認を経て会計データとして確定する AI マネージドサービスのプロトタイプ。

## セットアップ

```bash
cd 2026-04-15/prototype
npm install
```

## デモ実行

### 対話モード（人間が承認/修正/却下を判断）

```bash
npm run demo
```

各請求書に対して以下の操作が可能です。
- `y` — 承認
- `n` — 却下
- `c:XXXX` — 勘定科目を修正（例: `c:6300`）

### 自動承認モード

```bash
npm run demo:auto
```

高信頼度かつ既知取引先の仕訳は自動承認され、それ以外は人間確認として承認されます。

## アーキテクチャ

三層分離アーキテクチャを採用しています。

```
harness/        ハーネス層（品質制御・ドリフト防止）
  lifecycle.ts    ライフサイクルフック（before/after classify）
  checker.ts      品質チェック（信頼度評価・レビュー判定）
  planner.ts      終了条件管理（チェックリスト方式）

agent/          AIエージェント層（推論・分類）
  index.ts        請求書仕訳分類（パターン一致 / キーワードルール）

deterministic/  決定論的コード層（ルールベース処理）
  rules.ts        消費税検証・科目コード検証・重複検出

knowledge/      ナレッジ管理
  store.ts        パターン蓄積・改善提案生成
  improver.ts     フィードバックループ・レポート生成

demo/           デモ
  data-loader.ts  データ読込・初期パターン定義
  run.ts          CLIエントリポイント

data/           データ
  sample-invoices.json   サンプル請求書（5件）
  account-master.json    勘定科目マスタ（16科目）
```

## 実装済み機能

- ハーネスのライフサイクルフック（before/after classify）
- 終了条件の外部管理（チェックリスト方式、AI の自己申告不可）
- ナレッジの自動改善提案（修正蓄積からのルール化提案）
- ヒューマン・イン・ザ・ループ（対話的承認フロー）
- ドリフト対策（各ステップ後のバリデーション、重複検知）
