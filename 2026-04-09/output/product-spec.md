# InvoicePilot 設計書

## エレベーターピッチ
請求書を投入するだけで、AI が項目を抽出し、ハーネスが品質を保証し、決定論的コードが正確な仕訳データを生成する -- 経理担当者は「確認・承認」だけで月次処理が完了する AI マネージドサービス。

## ターゲットユーザー
- ペルソナ: 中小企業（従業員 50〜500 名）の経理担当者（1〜3 名体制）
- ペインポイント:
  - 月に 100〜500 件の請求書を手作業で処理している
  - 取引先ごとにフォーマットが異なり、目視確認に時間がかかる
  - 転記ミスや勘定科目の選択ミスが月次決算を遅延させる
  - インボイス制度対応の確認作業が追加負荷になっている
- 現在の解決方法:
  - Excel + 会計ソフトの手動入力
  - 一部は OCR サービスを使うが、後工程（仕訳生成）は手動
- 提供する価値:
  - 請求書処理の所要時間を 80%削減（目視確認 + 承認のみに）
  - 転記ミスをゼロに（決定論的コードによる金額検証）
  - 勘定科目の推定精度が使うほど向上（ナレッジ改善ループ）

## システムアーキテクチャ

### ハーネス層
- ライフサイクルフック:
  1. `beforeExtract`: 入力データの形式検証（JSON 構造チェック）
  2. `afterExtract`: 抽出結果の必須項目チェック（取引先名、日付、金額、明細が全て存在するか）
  3. `afterClassify`: 勘定科目推定の信頼度チェック（低信頼度の場合はヒューマンレビューへ）
  4. `afterJournalEntry`: 仕訳データの金額整合性チェック（借方合計 = 貸方合計）
- 終了条件の管理:
  - チェックリスト方式で管理（AI に自己申告させない）
  - [ ] 全必須項目の抽出完了
  - [ ] 金額整合性チェック OK（合計 = 明細合計 + 税額）
  - [ ] 勘定科目の確定（推定 or ヒューマン確定）
  - [ ] 仕訳データの生成完了
  - [ ] 借方・貸方の一致確認
- 品質チェック機構:
  - 金額の数値検証（消費税の再計算と照合）
  - 重複請求書の検知（請求書番号 + 取引先 + 金額の一致チェック）
  - 異常値検出（過去の取引金額との大幅な乖離を警告）
- サブエージェント構成:
  - プロトタイプでは単一エージェント。将来的には OCR エージェント + 分類エージェントに分割

### AIエージェント層
- 担当タスク（推論アップサイドが大きい部分）:
  1. 請求書テキストからの構造化データ抽出（取引先名、日付、金額、明細）
  2. 取引先名の名寄せ（表記揺れ吸収）
  3. 勘定科目の推定（過去パターンからの推論）
- 使用するツール/API:
  - Anthropic Claude API（claude-sonnet-4-20250514）: テキスト解析・構造化
  - プロトタイプでは OCR は省略し、テキスト/JSON 入力を前提とする
- ヒューマン・イン・ザ・ループのトリガー条件:
  - 勘定科目の推定信頼度が 80%未満の場合
  - 取引先マスタに未登録の新規取引先の場合
  - 金額が過去の同一取引先の平均から 50%以上乖離する場合

### 決定論的コード層
- 担当処理（ルールベースで確実に実行する部分）:
  1. 消費税額の計算・検証（税率テーブル参照: 10%, 8%軽減税率）
  2. 仕訳データの生成（借方/貸方の組み立て）
  3. 金額整合性チェック（合計金額 = Σ明細金額 + 消費税額）
  4. 重複検知（同一の請求書番号 + 取引先の組み合わせチェック）
  5. 会計ソフト向け CSV フォーマット変換

### ナレッジ自動改善ループ
1. **インプット（ユーザー行動/フィードバック）**:
   - ユーザーが修正した勘定科目の選択
   - 承認/差し戻しの判断
   - 取引先名の表記統一の選択
2. **矛盾検知メカニズム**:
   - 同一取引先に異なる勘定科目が割り当てられた場合に矛盾フラグを立てる
   - 過去の修正と異なる方向の修正が入った場合に確認を求める
3. **承認フロー**:
   - 改善提案をユーザーに提示（「取引先 X の仕入は常に『仕入高』に分類する」等の確認）
   - ユーザーが承認した場合のみナレッジに反映
4. **反映タイミング**:
   - 即時反映（承認直後から次回の推定に使用）
   - バッチ改善（月次で全ナレッジの整合性チェック）

## MVP（プロトタイプ）スコープ

### 実装する機能（3つ）
1. **請求書テキストからの構造化データ抽出 + ハーネスによる品質検証**
   - AI による項目抽出 → ハーネスの必須項目チェック → 金額の整合性検証
2. **勘定科目の推定 + ヒューマン・イン・ザ・ループ承認**
   - 過去のナレッジに基づく推定 → 信頼度判定 → 低信頼度の場合は CLI で人間に確認
3. **ナレッジの自動改善提案**
   - ユーザーの修正をナレッジストアに記録 → 次回の推定に反映

### 実装しない機能（将来版）
- OCR（画像/PDF からのテキスト抽出）-- プロトタイプではテキスト/JSON 入力
- 会計ソフトとの API 連携 -- プロトタイプでは CSV 出力
- 複数ユーザーの権限管理
- Web ダッシュボード（CLI で代替）
- 国税庁の適格請求書の発行事業者 DB 連携
