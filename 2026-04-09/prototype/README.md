# InvoicePilot プロトタイプ

請求書を投入するだけで、AI が項目を抽出し、ハーネスが品質を保証し、決定論的コードが正確な仕訳データを生成する AI マネージドサービスのプロトタイプ。

## アーキテクチャ（三層構造）

```
harness/          ハーネス層 -- AIの出力を「信頼せずに検証する」
  lifecycle.ts      ライフサイクルフック（before/afterの各フェーズで品質検証）
  checker.ts        終了条件チェックリスト（AIに自己申告させない）
  planner.ts        パイプライン統括（主導権はハーネスが持つ）

agent/            AIエージェント層 -- 推論のアップサイドが大きい部分を担当
  index.ts          請求書からの構造化データ抽出、勘定科目の推定

deterministic/    決定論的コード層 -- ルールベースで確実に実行
  rules.ts          消費税計算、仕訳データ生成、金額整合性チェック

knowledge/        ナレッジ管理
  store.ts          ストレージ（プロトタイプではJSON）
  improver.ts       自動改善ループ（ユーザーの修正を学習）

demo/             デモ
  run.ts            エントリポイント
```

## セットアップ

```bash
cd 2026-04-09/prototype
pnpm install
```

## デモ実行

```bash
pnpm demo
```

## デモで確認できること

1. ハーネスのライフサイクルフック（`[Harness] [OK] afterExtract` 等の出力）
2. 終了条件の外部管理（5 項目のチェックリストをハーネスが評価）
3. ヒューマン・イン・ザ・ループ（勘定科目の信頼度が低い場合に確認を求める）
4. 決定論的な金額検証（明細合計 + 税額 = 合計金額）
5. ナレッジの自動改善（処理した取引先の勘定科目を学習）
