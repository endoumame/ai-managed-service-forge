# InvoiceForge プロトタイプ

受領した請求書を AI が読み取り、ハーネスが品質を保証しながら正確な仕訳候補を生成するインボイス自動仕訳マネージドサービスのプロトタイプ。

## アーキテクチャ

```
harness/          ハーネス層（ライフサイクル管理・品質チェック・終了条件）
agent/            AIエージェント層（データ抽出・仕訳候補生成）
deterministic/    決定論的コード層（税計算・形式バリデーション）
knowledge/        ナレッジ管理（ルール蓄積・自動改善ループ）
demo/             デモ用エントリポイント
```

## セットアップ

```bash
cd 2026-05-04/prototype
pnpm install
```

## デモ実行

```bash
pnpm demo
```

## デモで実証される機能

1. **ライフサイクルフック**: 各処理フェーズ（抽出→分類→コミット）の前後でバリデーション実行
2. **終了条件の外部管理**: AI ではなくハーネスが「全フィールド抽出済み」「仕訳生成済み」「エラーなし」を判定
3. **ナレッジ自動改善**: 経理担当者の修正から仕訳ルールを提案→承認→適用するループ
4. **ヒューマン・イン・ザ・ループ**: 信頼度が閾値未満、新規取引先、金額異常時にレビューを要求
5. **ドリフト対策**: インボイス番号不正の請求書はパイプライン停止（AI の自己判断で通過させない）
