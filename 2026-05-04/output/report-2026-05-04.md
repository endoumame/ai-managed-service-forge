# 新機能パッケージ製品アイデア レポート
日時: 2026-05-04
ターゲットドメイン: 経理・請求書処理。

## 選定アイデア: InvoiceForge（インボイスフォージ）

### エレベーターピッチ
受領した請求書を AI が読み取り、ハーネスが品質を保証しながら正確な仕訳候補を生成し、経理担当者の修正を学習して日々賢くなるインボイス自動仕訳マネージドサービス。

### なぜこのアイデアを選んだか（ハーネスの価値観点）
仕訳作業は「OCR→抽出→分類→仕訳→記帳」という明確なパイプラインを持ち、各ステップにバリデーションフックを差し込む構造がそのままハーネスの設計になる。AI が「この仕訳で合っている」と自己判断するドリフト問題を、貸借一致チェックや過去パターンとの乖離検知で構造的に防げる。さらに、経理担当者の修正がそのまま学習データとなる自己改善ループが自然に成立するため、マネージドサービスとしての継続的な価値の向上が見込めます。全企業に必須だが競争優位に直結しない純粋なバックオフィス業務であり、コモディティ性が極めて高いです。インボイス制度により負荷が増加している中小企業にとって、マネージドサービスとして提供する経済合理性が最も高い領域です。

### プロトタイプで実証できたこと
- ハーネスのライフサイクルフック（beforeExtract/afterExtract/beforeClassify/afterClassify/beforeCommit）による多段バリデーション
- 終了条件の外部管理（CompletionPlanner が AI とは独立に 3 条件をチェック）
- ナレッジ自動改善ループ（ルール提案→人間承認→即座に次回適用）
- ヒューマン・イン・ザ・ループの自動トリガー（信頼度閾値、新規取引先、金額異常）
- ドリフト対策の実効性（インボイス番号不正の請求書でパイプライン停止を確認）

### プロトタイプの起動方法
```bash
cd 2026-05-04/prototype
pnpm install
pnpm demo
```

### 次のステップ（マネージドサービス化に向けて）
1. OCR 統合: PDF/画像からの請求書読取をパイプラインに組み込み（Claude Vision API または専用 OCR）
2. 会計ソフト連携: freee/マネーフォワード等の API と接続し、仕訳の自動記帳を実現
3. マルチテナント化: 企業ごとのナレッジ分離とルール管理の実装
4. ダッシュボード UI: 承認フロー・ルール管理・処理状況の可視化

### 学んだこと / 気づき
- ハーネスの「終了条件の外部管理」は、3 件のサンプルだけでも明確に価値を実証できた（INV-003 のインボイス番号不正でパイプライン停止）
- AI の信頼度スコアによるヒューマン・イン・ザ・ループの自動トリガーは、新規取引先（INV-002）で適切に機能した
- ナレッジの自動改善ループは、承認済みルールが即座に次の処理に反映される即時性が重要（INV-001 で承認済みルールにより信頼度 0.95 を達成）
- 決定論的コード（税計算、形式バリデーション）と AI 推論（品目分類、名寄せ）の分離は、テスト容易性と信頼性の両面で有効
