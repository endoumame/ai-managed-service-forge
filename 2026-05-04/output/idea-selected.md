## 選定結果: アイデア1「インボイス自動仕訳エンジン」

### 選定理由

1. **コモディティ性が最高（5点）**: 仕訳作業は全企業に必須だが、他社との差別化要因にならない純粋なバックオフィス業務。どの企業も「正しく記帳されていればよい」だけで、独自性を出す余地がない。

2. **ハーネスの価値が最も明確（5点）**: 請求書処理は「OCR→抽出→分類→仕訳→記帳」という明確なパイプラインを持ち、各ステップにバリデーションフックを差し込む構造がそのままハーネスの設計になる。AI が「この仕訳で合っている」と自己判断するドリフト問題を、貸借一致チェックや過去パターンとの乖離検知で防げる。

3. **自己改善ループが自然に成立（5点）**: 経理担当者が仕訳を修正するたびに「取引先×品目→勘定科目」のマッピングが更新される仕組みは、追加の設計なしで実現できる。

4. **プロトタイプ実現可能（4点）**: JSON 形式の請求書データ→仕訳候補生成→人間確認→ナレッジ更新のフローは、外部 API 依存を最小限にしてデモ可能。

5. **市場規模が最大（5点）**: インボイス制度により全事業者が適格請求書の管理を義務付けられ、特に中小企業の負荷が増大している。

## 選定プロダクト名: InvoiceForge（インボイスフォージ）
