# InvoiceForge 設計書

## エレベーターピッチ
受領した請求書を投入するだけで、ハーネスが品質保証した仕訳データが自動生成され、経理担当者は例外承認だけで月次決算を完了できるAIマネージドサービス。

## ターゲットユーザー
- **ペルソナ**: 中小企業の経理担当者（従業員50〜500名規模、月間請求書50〜500枚）
- **ペインポイント**:
  - 請求書のフォーマットがバラバラで、手作業での転記・仕訳に毎月数日かかる
  - 仕訳科目の判断が属人化しており、担当者不在時にミスが増える
  - 月末・期末に集中する作業負荷で残業が常態化
- **現在の解決方法**:
  - 手作業でのExcel入力 → 会計ソフトへの転記
  - OCRツール導入済みでも仕訳判断は人間が実施
  - 外注（記帳代行）は月額コストが高く、リアルタイム性に欠ける
- **提供する価値**:
  - 仕訳作業工数の80%削減
  - 仕訳ミスの大幅減少（ハーネスによる多重チェック）
  - 属人化の解消（ナレッジが組織知として蓄積）

## システムアーキテクチャ

### ハーネス層
- **ライフサイクルフック**:
  - `beforeExtract`: 入力データのフォーマット検証（ファイル形式、サイズ、破損チェック）
  - `afterExtract`: 抽出結果の完全性チェック（必須フィールドの存在確認）
  - `afterClassify`: 仕訳科目の妥当性チェック（過去パターンとの乖離度スコアリング）
  - `beforeOutput`: 最終出力の金額整合性検証（税込 = 税抜 + 消費税）
- **終了条件管理**:
  - チェックリスト形式で外部管理（AIに自己申告させない）
  - [ ] 全必須フィールドが抽出済み
  - [ ] 仕訳科目が確定済み（自動 or 人間承認）
  - [ ] 金額整合性チェックがパス
  - [ ] 出力フォーマット検証がパス
- **品質チェック機構**:
  - 金額の算術的整合性（小計 + 税 = 合計）
  - 過去同一取引先の仕訳パターンとの乖離検知（閾値超えで要承認フラグ）
  - 抽出信頼度スコアの閾値管理（低信頼度は自動的に人間レビューへ）
- **サブエージェント構成**:
  - `ExtractorAgent`: 請求書からのデータ抽出特化
  - `ClassifierAgent`: 仕訳科目の推定特化
  - 各エージェントは独立しており、ハーネスが結果を統合・検証

### AIエージェント層
- **担当タスク（推論アップサイドが大きい部分）**:
  - 非定型請求書のレイアウト解析・項目抽出
  - 仕訳科目の推定（取引先名・品目名からの類推）
  - 曖昧な品目名の正規化（「コンサル料」「コンサルティングフィー」→同一科目）
- **使用するツール/API**:
  - Claude API（claude-sonnet-4-20250514）: 請求書解析・仕訳推定
  - Structured Output: 抽出結果のJSON出力を強制
- **ヒューマン・イン・ザ・ループのトリガー条件**:
  - 仕訳科目の信頼度スコアが閾値（80%）未満
  - 新規取引先の初回処理
  - 過去パターンとの乖離度が閾値超え
  - 金額整合性チェック不合格

### 決定論的コード層
- **担当処理（ルールベースで確実に実行する部分）**:
  - 消費税計算（税率テーブル × 税抜金額）
  - 金額整合性バリデーション
  - 勘定科目コードのマスタ参照
  - 会計ソフト向けCSVフォーマット生成
  - 日付フォーマットの正規化
  - インボイス制度の適格請求書要件チェック（登録番号フォーマット検証）

### ナレッジ自動改善ループ
1. **インプット（ユーザー行動/フィードバック）**:
   - 仕訳科目の修正操作（AIの推定を人間が訂正）
   - 「承認」操作（AIの推定が正しかった確認）
   - 新規取引先・新規品目の初回判断
2. **矛盾検知メカニズム**:
   - 同一取引先×同一品目に対して、過去と異なる仕訳科目が選択された場合にフラグ
   - 月次で修正率が上昇傾向の取引先パターンをアラート
3. **承認フロー**:
   - ナレッジ更新提案を管理者に提示（「取引先A×品目B → 科目Cに変更しますか？」）
   - 承認されたもののみルールに反映
4. **反映タイミング**:
   - 承認済み更新は即時反映
   - 月次でナレッジ全体の整合性レビューを実施

## MVP（プロトタイプ）スコープ
実装する機能（3つに絞る）:
1. **請求書データ抽出 + 仕訳科目推定**: 請求書JSON入力からAIがデータ抽出・仕訳推定を行う
2. **ハーネスによる品質チェック + 承認フロー**: 金額整合性チェック、パターン乖離検知、人間承認のCLIインターフェース
3. **ナレッジ自動改善提案**: 人間の修正フィードバックを蓄積し、次回処理で精度向上を実証

実装しない機能（将来版）:
- 実際のOCR処理（プロトタイプではJSON入力で代替）
- 会計ソフト連携（CSV出力まで）
- マルチテナント対応
- Webダッシュボード（CLIで代替）
- バッチ処理（1枚ずつ処理で実証）
