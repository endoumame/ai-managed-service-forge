# ContractShield - 契約書リスク自動スクリーニング プロトタイプ

契約書をアップロードするだけでリスク条項を自動検出し、修正案付きのレビューレポートを生成する AI マネージドサービスのプロトタイプ。

## アーキテクチャ

AI エージェント + ハーネス + 決定論的コードの三位一体構成。

```
prototype/
├── harness/           # ハーネス層（ライフサイクル管理）
│   ├── lifecycle.ts   # before/afterフック（パース・分析・レポート）
│   ├── checker.ts     # 品質チェック（必須条項・確信度）
│   └── planner.ts     # 終了条件チェックリスト管理
├── agent/             # AIエージェント層
│   └── index.ts       # 条項リスク分析（Claude API / モック）
├── deterministic/     # 決定論的コード層
│   ├── rules.ts       # 契約書パース・条項分類
│   └── report.ts      # レポート生成・フォーマット
├── knowledge/         # ナレッジ管理
│   ├── store.ts       # ナレッジDB（インメモリ）
│   └── improver.ts    # 自動改善ループ
├── demo/              # デモ用エントリポイント
│   ├── run.ts         # メインパイプライン
│   └── output.ts      # 出力ユーティリティ
└── types.ts           # 共通型定義
```

## 設計上のポイント

### ハーネスによるドリフト防止

- 各処理フェーズの前後にライフサイクルフックを実行
- 終了条件をチェックリスト方式で外部管理（AI に自己申告させない）
- 高リスク条項がある場合、人間レビューなしに完了を許さない

### AIと決定論的コードの分離

- AI 担当: 条項の意味理解、リスクパターン認識、修正案生成
- 決定論的コード担当: 契約書パース、条項分類、スコア計算、レポート生成
- この分離により、AI のドリフトの影響範囲を最小化

### ナレッジ自動改善ループ

- ユーザーがリスク判定を修正 → 改善提案として記録
- 管理者の承認を経てナレッジ DB に反映（自動反映しない）
- 次回レビュー時に過去の修正パターンを活用
