# InvoiceForge - AIマネージドサービス プロトタイプ

請求書受領から仕訳登録までを自動化するAIマネージドサービスのプロトタイプ。

## アーキテクチャ

```
prototype/
├── harness/           # ハーネス層（パイプライン制御・品質保証）
│   ├── lifecycle.ts   # ライフサイクルフック（before/after各ステージ）
│   ├── checker.ts     # 終了条件チェックリスト
│   └── planner.ts     # パイプラインプランナー
├── agent/             # AIエージェント層（推論アップサイドが大きい処理）
│   └── index.ts       # 請求書データ抽出・勘定科目推定
├── deterministic/     # 決定論的コード層（ルールベースで確実に処理）
│   └── rules.ts       # 仕訳生成・税計算・承認ルール
├── knowledge/         # ナレッジ管理（自己改善ループ）
│   ├── store.ts       # インメモリナレッジストア
│   └── improver.ts    # 改善提案生成・矛盾検知
├── demo/              # デモ用エントリポイント
│   ├── run.ts         # メイン実行スクリプト
│   ├── logger.ts      # ロガー
│   └── sample-data.ts # サンプルデータ
├── data/              # サンプルデータ（JSON）
├── types.ts           # 型定義
└── package.json
```

## セットアップ

```bash
cd prototype
pnpm install
```

## デモ実行

```bash
npx tsx demo/run.ts
```

## 実証ポイント

1. **ハーネスによる品質保証**: AIの抽出結果を信頼せず、信頼度スコア・貸借一致・金額異常を外部チェック
2. **終了条件の外部管理**: AIの自己申告ではなく、チェックリストで客観的に完了を判定
3. **ナレッジ自動改善ループ**: ユーザーの修正履歴から仕訳ルールの更新を自動提案（人間承認付き）
