# 新機能パッケージ製品アイデア レポート
日時: 2026-04-04。
ターゲットドメイン: 経理・請求書処理。

## 選定アイデア: InvoiceForge（請求書の自動仕訳・会計連携サービス）

### エレベーターピッチ
請求書 PDF を投入するだけで、ハーネスによる品質保証済みの正確な仕訳データを会計ソフト連携形式で出力する、AI マネージドな請求書処理サービスです。

### なぜこのアイデアを選んだか（ハーネスの価値観点）
請求書処理は金額の正確性において非常に重要な領域であり、AI の自己申告を信用してはいけません。ハーネスによる貸借一致・税率整合性・金額桁数の決定論的な検証で、出力品質を保証する構造を直感的に伝えられます。AI / ハーネス / 決定論的コードの三層をクリーンに分離でき、「AI マネージドサービス」を体現するのに最適でした。さらに、ユーザーの修正履歴を自然にナレッジとして蓄積でき、自己改善ループの実装に最も適したドメインでもあります。

### プロトタイプで実証できたこと
- ハーネスのライフサイクルフック（before/after）が各ステップで自動実行され、AI の出力を決定論的に検証できること
- 終了条件チェックリスト（6 項目）がハーネス側で管理され、AI が変更できない構造であること
- 貸借一致チェック・税率整合性チェックが決定論的コードとして正しく機能すること
- ナレッジ改善ループ: ユーザー修正 3 回の蓄積 → ルール化提案 → 承認 → ナレッジストア反映の一連のフローが動作すること
- 品質チェック集約により、ヒューマン・イン・ザ・ループの必要性を自動判定できること

### プロトタイプの起動方法
```bash
cd 2026-04-04/prototype
npx tsx demo/run.ts
```

### 次のステップ（マネージドサービス化に向けて）
1. Claude API 連携: 現在のパターンマッチ抽出を Claude API による高精度な構造化データ抽出に差し替え、PDF/画像 OCR にも対応する
2. 会計ソフト連携: freee/マネーフォワード/弥生の API と接続し、仕訳データの直接インポートを実現する
3. マルチテナント対応: 企業ごとのナレッジストア分離、権限管理、承認ワークフローの Web ダッシュボード化

### 学んだこと / 気づき
- ハーネスの「終了条件の外部管理」は、チェックリストをデータとして定義し、評価関数をマッピングする設計が有効。AI がチェックリスト自体を操作できない構造が重要
- ドリフト対策として「信頼度スコアの閾値による自動承認/手動レビューの振り分け」は、実運用で最も価値が高いヒューマン・イン・ザ・ループの形態
- ナレッジ改善ループの「N 回同じ修正 → ルール化提案 → 人間承認」というフローは、AI の学習をユーザーが制御可能な形で提供できる良いパターン
- 決定論的コードに任せるべき処理（税率計算、貸借一致チェック）を明確に分離することで、AI の推論エラーが致命的な結果を招かない設計が実現できる
