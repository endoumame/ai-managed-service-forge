# InvoiceForge 設計書

## エレベーターピッチ
請求書 PDF を投入するだけで、ハーネスが品質保証した正確な仕訳データが会計ソフト連携形式で出力される、AI マネージドな請求書処理サービス。

## ターゲットユーザー
- **ペインポイント**: 月数十〜数百枚の請求書を手作業で仕訳入力している。OCR ツールを導入しても結局目視確認が必要で、工数削減効果が薄い。
- **現在の解決方法**: 経理担当者が 1 枚ずつ請求書を見て会計ソフトに手入力。または半自動 OCR ツール＋手動補正。
- **提供する価値**:「投入→確認→承認」の 3 ステップで仕訳が完了。AI が読み取り、ハーネスが検証し、人間は例外だけ確認すればよい。

## システムアーキテクチャ

### ハーネス層
- **ライフサイクルフック**:
  - `beforeExtraction`: 入力ファイル形式チェック、テキスト抽出前のノーマライゼーション
  - `afterExtraction`: 必須フィールド（日付、金額、取引先名、摘要）の存在チェック
  - `beforeClassification`: 勘定科目マスタの存在確認
  - `afterClassification`: 貸借一致チェック、税率の法的整合性チェック、金額桁数の妥当性チェック
  - `beforeOutput`: 出力フォーマットのスキーマバリデーション
- **終了条件管理**:
  チェックリスト形式で外部ファイルに定義（AI が動的に変更不可）:
  1. [ ] 全必須フィールドが抽出されている
  2. [ ] 取引先名がマスタに照合済み（または新規として登録待ち）
  3. [ ] 勘定科目が付与されている
  4. [ ] 貸借が一致している
  5. [ ] 税率が法定税率テーブルに存在する
  6. [ ] 過去の同一取引先の仕訳と乖離率が閾値以内
- **品質チェック機構**:
  - 金額の桁数異常検知（過去平均の 10 倍以上で警告）
  - 日付の妥当性（未来日付、1 年以上前の日付を警告）
  - 信頼度スコアによる自動承認/手動確認の振り分け
- **サブエージェント構成**:
  - ExtractorAgent: 請求書からの情報抽出特化
  - ClassifierAgent: 勘定科目分類特化

### AIエージェント層
- **担当タスク（推論アップサイドが大きい部分）**:
  - 請求書テキストからの構造化情報抽出（日付、金額、取引先名、摘要、明細行）
  - 勘定科目の推定（過去の仕訳パターン + 摘要の意味理解）
  - 取引先名の名寄せ（「(株)ABC」「ABC 株式会社」「abc corp」→ 同一取引先）
- **使用するツール/API**:
  - Claude API（テキスト理解・分類）
  - PDF テキスト抽出ライブラリ（決定論的前処理）
- **ヒューマン・イン・ザ・ループのトリガー条件**:
  - 信頼度スコアが閾値未満（勘定科目推定の確信度が低い）
  - 新規取引先（マスタに存在しない取引先名）
  - 金額の桁数異常（過去パターンとの乖離が大きい）
  - ハーネスの品質チェックで警告が出た場合

### 決定論的コード層
- **担当処理（ルールベースで確実に実行する部分）**:
  - 消費税計算: 税率テーブル（10%, 8%軽減税率）× 税抜金額
  - 貸借バランスチェック: 借方合計 === 貸方合計
  - 仕訳フォーマット変換: 内部形式 → freee CSV / マネーフォワード CSV / 弥生インポート形式
  - 重複請求チェック: 請求番号 + 取引先 + 金額 + 日付の exact match
  - 日付計算: 支払期日の算出（月末締め翌月末払い等のルール適用）

### ナレッジ自動改善ループ
1. **インプット（ユーザー行動/フィードバック）**:
   - ユーザーが仕訳を修正した場合の修正前後データ
   - 「承認」「却下」の判断データ
   - 新規取引先の登録データ
2. **矛盾検知メカニズム**:
   - 同一取引先×類似摘要なのに異なる勘定科目が付与されたケースを検出
   - 既存ルールと矛盾する修正が入った場合にフラグ
3. **承認フロー**:
   - 同一パターンの修正が N 回（デフォルト 3 回）蓄積されたら、ルール化を提案
   - 提案内容を人間がレビュー・承認してからナレッジに反映
4. **反映タイミング**:
   - 承認後即座にナレッジストアに反映（次回の仕訳から適用）

## MVP（プロトタイプ）スコープ
実装する機能（3 つに絞る）:
1. **請求書テキストからの情報抽出 + 仕訳生成**: テキスト形式の請求書データを入力し、構造化データを抽出してから勘定科目を推定し仕訳を生成
2. **ハーネスによる品質保証**: ライフサイクルフック（before/after）、終了条件チェックリスト、品質チェック（貸借一致・税率整合性・金額異常検知）
3. **ナレッジの自動改善提案**: ユーザー修正の蓄積から勘定科目マッピングルールの改善を提案する仕組み

実装しない機能（将来版）:
- PDF/画像の OCR（プロトタイプではテキスト入力）
- 会計ソフトとの API 連携（CSV エクスポートまで）
- マルチユーザー対応・権限管理
- Web ダッシュボード（CLI のみ）
- 複数通貨対応
