# InvoiceForge プロトタイプ

請求書 PDF を投入するだけで、ハーネスによる品質保証済みの正確な仕訳データを会計ソフト連携形式で出力する、AI マネージドな請求書処理サービスです。

## アーキテクチャ

```
harness/          ← ハーネス層（ライフサイクル管理・品質チェック・終了条件）
  lifecycle.ts    - before/after フック（抽出・分類・仕訳の各段階で自動実行）
  checker.ts      - 品質チェック集約（信頼度・エラー・警告の統合判定）
  planner.ts      - 終了条件チェックリスト（AIが変更不可、外部管理）

agent/            ← AIエージェント層（推論のアップサイドが大きい処理）
  index.ts        - 請求書テキスト抽出・勘定科目分類

deterministic/    ← 決定論的コード層（ルールベースで確実に実行）
  rules.ts        - 税額計算・貸借バランス・CSV変換

knowledge/        ← ナレッジ管理（自己改善ループ）
  store.ts        - マッピングルールのストレージ
  improver.ts     - ユーザー修正からのルール改善提案

demo/             ← デモ用エントリポイント
  run.ts          - パイプライン全体の実行

data/             ← サンプルデータ
  sample-invoice.txt
  knowledge.json
```

## セットアップ

```bash
cd 2026-04-04/prototype
```

## デモ実行

```bash
npx tsx demo/run.ts
```

## 実装済み機能

- [x] ハーネスのライフサイクルフック（before/after Tool コール）
- [x] 終了条件の外部管理（AI に自己申告させない）
- [x] ナレッジの自動改善提案（修正履歴の蓄積 → ルール化提案 → 承認フロー）
- [x] ヒューマン・イン・ザ・ループの接点（承認フロー、信頼度閾値による振り分け）
- [x] デモ実行可能なエントリポイント

## ドリフト対策

1. 終了条件チェックリストをハーネスが保持（AI は変更不可）
2. 各ステップ完了後に外部バリデーション（貸借一致、税率整合性、金額桁数）
3. 信頼度スコアによる自動承認/手動確認の振り分け
