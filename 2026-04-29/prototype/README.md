# InvoiceForge — 請求書自動仕訳マネージドサービス（プロトタイプ）

請求書データを投入すると、AI が構造化データを抽出し、ハーネスが数値整合性と仕訳ルールを検証し、承認待ちの仕訳データとして出力する。

## アーキテクチャ

```
harness/          ← ハーネス層: ライフサイクル管理・品質ゲート・終了条件
  lifecycle.ts       フック定義（before/after extraction, journal entry）
  checker.ts         品質チェック（信頼度・異常検知）
  planner.ts         終了条件チェックリスト・進捗管理

agent/            ← AIエージェント層: 推論（抽出・仕訳候補提案）
  index.ts           請求書抽出・仕訳生成・異常検知

deterministic/    ← 決定論的コード層: ルールベース処理
  rules.ts           税計算・重複チェック・勘定科目マッピング・貸借検証

knowledge/        ← ナレッジ管理: 学習・改善提案
  store.ts           承認パターンの永続化
  improver.ts        自動改善提案の生成

demo/             ← デモ用エントリポイント
  run.ts             CLIデモ実行
  mock-invoices.json モックデータ（5件、うち1件重複）
```

## セットアップ

```bash
cd 2026-04-29/prototype
pnpm install
```

## デモ実行

### 自動承認モード（非対話）

```bash
npx tsx demo/run.ts --auto-approve
```

### 対話モード（ヒューマン・イン・ザ・ループ）

```bash
npx tsx demo/run.ts
```

各仕訳候補に対して `y/n` で承認/却下を行う。

## デモで確認できること

1. **ハーネスによる品質ゲート**: 数値整合性（小計+税=合計）の自動検証
2. **重複請求書の検出**: 請求書番号ベースの決定論的チェック
3. **仕訳候補の自動提案**: キーワードマッチによる勘定科目推定
4. **貸借バランス検証**: 借方合計=貸方合計の厳密チェック
5. **ヒューマン・イン・ザ・ループ**: 信頼度が低い場合・新規取引先の場合に人間レビューを要求
6. **終了条件の外部管理**: AI の自己申告ではなくチェックリストで進捗管理
7. **ナレッジ蓄積**: 承認された仕訳パターンを JSON に永続化
