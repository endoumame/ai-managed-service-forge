# JournalCraft — AI仕訳起票アシスタント プロトタイプ

取引テキストから複式簿記の仕訳を自動生成する AI マネージドサービスのプロトタイプ。

## アーキテクチャ

```
┌─────────────────────────────────────────┐
│           ハーネス層 (harness/)           │
│  ライフサイクル管理 / 品質チェック / 終了条件  │
├─────────────────────────────────────────┤
│  AIエージェント層    │  決定論的コード層      │
│  (agent/)          │  (deterministic/)    │
│  テキスト抽出       │  バランスチェック      │
│  勘定科目推論       │  税計算              │
│  パターン認識       │  承認ルーティング      │
├─────────────────────────────────────────┤
│         ナレッジ層 (knowledge/)           │
│   パターンDB / 自動改善ループ              │
└─────────────────────────────────────────┘
```

## セットアップ

```bash
cd 2026-04-30/prototype
npm install
```

## デモ実行

```bash
npm run demo
```

4 件のサンプル取引を処理し、以下の点を実証します。

1. ナレッジ DB からの高確信度マッチング（家賃→95%で自動承認候補）
2. AI モック推論による分類（タクシー→70%で人間承認必要）
3. 借貸バランスの決定論的検証
4. ナレッジ自動改善提案の生成

## ディレクトリ構成

```
prototype/
├── types.ts              # 共通型定義
├── harness/
│   ├── lifecycle.ts      # ライフサイクルフック管理
│   ├── checker.ts        # 品質チェック（抽出/仕訳バリデーション）
│   └── planner.ts        # 終了条件チェックリスト管理
├── agent/
│   └── index.ts          # AI推論（モック/ナレッジ参照）
├── deterministic/
│   └── rules.ts          # 勘定科目マスタ/税計算/バランスチェック
├── knowledge/
│   ├── store.ts          # パターンDB（インメモリ）
│   └── improver.ts       # 自動改善ループ（矛盾検知/新規提案）
└── demo/
    └── run.ts            # デモエントリポイント
```
