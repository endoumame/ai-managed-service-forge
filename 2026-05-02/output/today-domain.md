# ターゲットドメイン選定

日時: 2026-05-02。

## 選定ドメイン: 経理・請求書処理

## 選定理由

1. **コモディティ性が極めて高い**: 請求書処理は全企業に共通する業務であり、競争優位に直結しない典型的なバックオフィス業務である。企業が内製する理由は薄く、マネージドサービスとしての経済合理性が最も高い。

2. **ハーネスの価値が明確**: 請求書処理は「読み取り → 分類 → 仕訳 → 承認 → 記帳」という明確なライフサイクルを持ち、各ステップで品質チェック（金額の整合性、勘定科目の妥当性）を挟む必要がある。AI に自己完了を宣言させると金額ミスが発生するため、ハーネスによる外部バリデーションが不可欠。

3. **AI＋決定論的コードの分離が明快**: OCR/自然言語理解（AI 向き）と税計算・仕訳ルール（決定論的コード向き）の境界が明確で、プロトタイプでアーキテクチャの価値を実証しやすい。

4. **自己改善ループが自然に設計できる**: ユーザーが仕訳を修正するたびにナレッジが蓄積され、次回以降の精度が向上する「フィードバック→学習」の循環が直感的。

5. **初回実行として適切**: 10 ドメインの中で最も汎用性が高く、AI マネージドサービスの概念実証として説得力がある。
