# InvoiceForge プロトタイプ

請求書の自動仕訳マネージドサービスのプロトタイプ実装。

## アーキテクチャ

AI エージェント + ハーネス + 決定論的コードの三位一体構造。

```
harness/        ハーネス層（ライフサイクル管理・品質チェック・終了条件）
agent/          AIエージェント層（勘定科目推定・異常検知）
deterministic/  決定論的コード層（税計算・貸借検証・日付チェック）
knowledge/      ナレッジ管理（ルール蓄積・自動改善ループ）
demo/           デモ用エントリポイント
data/           サンプルデータ・勘定科目マスタ・ナレッジベース
```

## セットアップ

```bash
cd 2026-05-02/prototype
npm install
```

## デモ実行

```bash
npx tsx demo/run.ts
```

## デモで実証されること

1. ハーネスによるライフサイクル管理: 抽出→分類→仕訳の各ステップに品質ゲート
2. 終了条件の外部管理: AI に自己完了を宣言させず、チェックリストで判定
3. ナレッジの自動改善提案: 仕訳修正→ルール提案→承認フロー
