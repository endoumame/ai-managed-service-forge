# アイデア評価・選定

**日付**: 2026-05-25
**ドメイン** — 経理・請求書処理。

## 評価詳細

### 1位: InvoiceForge（25点）— 選定

- コモディティ性 5 点 — 請求書処理は業種を問わず全企業に存在。競争優位とは無関係な典型的バックオフィス業務。
- ハーネスの価値明確性 5 点 —「AI 読み取り→決定論的検証→人間承認」のサイクルがハーネスの全機能（Before/After フック、終了条件管理、品質チェック）を活かす理想的なユースケース。ハーネスなしでは AI の誤読を検知できない。
- 自己改善ループ 5 点 —「取引先→勘定科目」のマッピングが処理ごとに自然に蓄積。人間の修正が直接的にナレッジ改善に繋がる極めて明確なフィードバックループ。
- プロトタイプ実現可能性 5 点 — 請求書テキスト→仕訳データの変換パイプラインは CLI で完結可能。外部 API への依存も最小限。
- 市場規模 5 点 — 国内だけでも freee/マネーフォワード/弥生の市場を考えると数千億円規模。中小企業から大企業まで適用可能。

### 同率2位について

- ExpenseGuard — ハーネスの価値は高いが、経費精算ソフト（楽楽精算等）との差別化が必要。
- ReconcileBot — 自己改善ループが優秀だが、銀行 API との連携がプロトタイプのハードル。
- TaxPrepForge — コモディティ性は高いが、税法の正確性が求められプロトタイプの検証が難しい。

### 最下位について

- InvoiceWatch — キャッシュフロー予測は有用だが、ハーネスの価値がやや不明確。予測系タスクは AI 単体でも成立しやすく、ハーネスの三位一体モデルの強みが出にくい。

## 選定結果

**InvoiceForge — 請求書の自動仕訳・記帳マネージドサービス** を選定。

選定理由の要約: 全 5 評価軸で最高スコアを獲得。特に「ハーネスの三位一体アーキテクチャが最も自然に活きるユースケース」であり、AI マネージドサービスのコンセプト実証として最適。
