# InvoiceForge - 請求書の自動仕訳マネージドサービス（プロトタイプ）

請求書テキストを投入するだけで、会計ソフトにインポート可能な仕訳データを自動生成する AI マネージドサービスのプロトタイプです。

## アーキテクチャ

三位一体構成（ハーネス + AI エージェント + 決定論的コード）は以下の通りです。

```
harness/         ハーネス層（ライフサイクル管理・品質チェック・終了条件管理）
agent/           AIエージェント層（請求書項目抽出・勘定科目推定）
deterministic/   決定論的コード層（税額計算・金額突合・フォーマット変換）
knowledge/       ナレッジ管理（自動改善ループ・矛盾検知・承認フロー）
demo/            デモ用エントリポイント
```

## セットアップ

```bash
cd 2026-05-25/prototype
npm install
```

## デモ実行

### モックモード（AIなし）

```bash
npm run demo:no-ai
```

### Claude API使用

```bash
export ANTHROPIC_API_KEY="your-api-key"
npm run demo
```

## 実装済み機能

1. ハーネスのライフサイクルフック（before/after extract, before/after classify）
2. 終了条件の外部管理（チェックリスト形式、AI に自己申告させない）
3. ナレッジの自動改善提案（矛盾検知、新規マッピング提案）
4. ヒューマン・イン・ザ・ループの接点（承認フロー）
5. 決定論的検証（税額再計算、貸借バランスチェック、勘定科目バリデーション）
