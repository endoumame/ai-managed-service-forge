# ターゲットドメイン選定

日時: 2026-04-05。

## 選定ドメイン

**経理・請求書処理**

## 選定理由

1. **コモディティ性が極めて高い**: 請求書の受領→データ抽出→仕訳→承認→支払という一連のフローは、ほぼ全企業が抱える定型業務であり、競争優位に直結しない。内製する経済合理性が低い。

2. **ハーネスの価値が最も明確**: 請求書処理は「正確さ」が最重要。AI の自己申告（「正しく読み取れました」）を信じてはならない領域。ハーネスによる外部バリデーション（金額突合、フォーマットチェック、承認フロー）が不可欠。

3. **AI×決定論的コードの分離が自然**: OCR/自然言語理解（AI 向き）と、仕訳ルール・税計算・フォーマット変換（決定論的コード向き）がきれいに分かれる。

4. **自己改善ループを構築しやすい**: 人間の修正した仕訳パターンを蓄積することで、時間とともに精度が向上する仕組みを自然に組み込める。

5. **初回実行として最適**: ドメインの理解が広く共有されており、プロトタイプのデモが直感的にわかりやすい。
