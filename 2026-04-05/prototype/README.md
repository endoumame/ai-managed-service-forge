# InvoiceForge プロトタイプ

請求書の自動仕訳マネージドサービスのプロトタイプ実装。

## アーキテクチャ

3 層構成で AI マネージドサービスを実現します。

- **harness/** — ハーネス層: ライフサイクルフック、品質チェック、終了条件管理
- **agent/** — AI エージェント層: データ抽出、勘定科目推定、異常検知
- **deterministic/** — 決定論的コード層: 税計算、仕訳生成、重複チェック
- **knowledge/** — ナレッジ管理: マッピングストア、自動改善ループ
- **demo/** — デモ実行エントリポイント

## セットアップ

```bash
cd 2026-04-05/prototype
```

## デモ実行

```bash
npx tsx demo/run.ts
```

## デモで実証すること

1. ハーネスによる AI 出力の外部バリデーション（信頼しないアーキテクチャ）
2. 終了条件の外部管理（AI に自己申告させない）
3. ナレッジ改善提案 + ヒューマン・イン・ザ・ループの承認フロー
