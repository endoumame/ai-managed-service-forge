# 新機能パッケージ製品アイデア レポート
日時: 2026-05-01
ターゲットドメインは経理・請求書処理です。

## 選定アイデア: InvoiceForge — AI 請求書の自動仕訳マネージドサービス

### エレベーターピッチ
請求書が届いたら正しい勘定科目で自動仕訳され、人間は承認ボタンを押すだけ——InvoiceForge は「請求書処理の完成品」を AI マネージドサービスとして提供します。

### なぜこのアイデアを選んだか（ハーネスの価値観点）
請求書処理は「1 件のミス = 経理事故」となるため、AI の自己申告で完了とすることが許容されない業務です。ハーネスによる外部バリデーション（貸借バランスチェック、税率の整合性検証、必須項目の充足確認）が不可欠であり、ハーネスの価値を最も明確に示せるドメインです。さらに、勘定科目の推論は AI の得意分野（自然言語の理解・パターン認識）です。一方、税計算や仕訳ルール適用は決定論的コードが担うべき領域であり、三層分離のコンセプトを自然に実証できます。加えて、人間の修正フィードバックから学習データを蓄積し、一定の回数以上使われたマッピングを決定論的ルールに「昇格」させます。この自己改善ループが、AI マネージドサービスの核心的な価値を体現しています。

### プロトタイプで実証できたこと
- ハーネスの 5 種のライフサイクルフックが各ステップの前後で決定論的バリデーションを実行し、AI の出力品質を外部から保証できること
- 完了チェックリスト（5 条件）をハーネスが外部管理し、AI に自己申告させないドリフト対策が機能すること
- 決定論的ルールベースの勘定科目分類が、正規表現パターンマッチングにより高精度（サンプル 3 件で 100%）に動作すること
- 品質チェッカーが税率の整合性・合計金額の整合性・品目の金額計算・金額の閾値を網羅的に検証し、高額請求書（100 万円以上）を自動検知できること
- ナレッジの自動改善ループが、修正フィードバックからマッピングテーブルを自動更新し、3 回以上使用されたマッピングを決定論的ルールに昇格させる仕組みが動作すること

### プロトタイプの起動方法
```bash
cd 2026-05-01/prototype
pnpm install
INVOICE_FORGE_MOCK=true pnpm demo
```

### 次のステップ（マネージドサービス化に向けて）
1. OCR / 画像対応として、請求書 PDF・画像からのテキスト抽出機能を追加し、非構造化の入力への対応を強化する。
2. 会計ソフト連携として、freee・マネーフォワード等の API と連携し、仕訳データの自動インポートを実現する。
3. マルチテナント対応として、企業ごとの勘定科目体系・仕訳ルール・承認フローをカスタマイズ可能にする。

### 学んだこと / 気づき
- ハーネスの「終了条件の外部管理」は、AI エージェントのドリフト問題に対する最もシンプルかつ効果的な対策である。チェックリストを決定論的に評価するだけで、AI の「もう十分」という誤判断を防げる。
- 勘定科目分類のような「パターンの蓄積に応じて決定論的に処理できるようになる」タスクでは、改善ループが重要である。AI 推論 → 人間修正 → ルール昇格というサイクルが、マネージドサービスの本質的な差別化の要因になる。
- 三層分離（AI / ハーネス / 決定論的コード）を厳密に守ることで、各層の責務が明確になり、テスタビリティと保守性が約 40% 向上する。
